# Changelog

All notable changes to this project are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [Unreleased]

### Added
- Automated demo GIF and MP4 generation tooling using Puppeteer & FFmpeg.
- Mock transcription mode for offline testing and fast demo generation.
- GitHub Actions continuous integration (CI) workflow for linting, testing, and building.
- Comprehensive discoverability upgrade (README overhaul, social preview card, MIT license).

### Changed
- Refined French localization across the interface and components.

## [0.1.0] - 2024-10-01

### Added
- Initial release of AI Invoice Transcribe.
- Next.js App Router setup with Tailwind CSS and Radix UI components.
- Mistral Document AI OCR API integration (`/api/transcribe`).
- Markdown JSON extraction parser for invoice structures.
- Multi-file drag-and-drop upload zone and batch queue.
- Real-time JSON preview and file download actions.
